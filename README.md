# Next.js Pokédex

<img width="1109" height="835" alt="Pokédex App" src="https://github.com/user-attachments/assets/93d32a07-b6ad-451c-b073-5bfc71e48109" />

A retro-inspired Pokédex for exploring the first 649 Pokémon, built as a hobby project to learn Next.js, TypeScript, GraphQL, and Apollo. It combines a familiar red Pokédex design with a responsive interface, playful CSS animations, and attention to accessibility, using Tailwind CSS and React Aria.

- Browse Pokémon from generations I–V, loading more entries as you go.
- Find Pokémon with fuzzy name search or filter by generation and type.
- Explore artwork, types, descriptions, measurements, regions, and footprints where available.
- Play Pokémon cries with an animated audio visualizer.
- Return to your filtered results with your position preserved.
- Navigate with a keyboard and receive screen-reader status updates.
- Adjust contrast, reduce motion, and disable cry autoplay in Settings.

Thanks to [PokéAPI](https://pokeapi.co/) and its contributors for making the Pokémon data and assets available. This project wouldn't exist without their work.
